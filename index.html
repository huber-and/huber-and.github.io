Atlassian Tools

Publishes Antora-generated documentation to Confluence Cloud. Maps several local documentation trees to several spaces in one build, rewrites internal links so they resolve across spaces, uploads images as attachments, and keeps the space in sync by trashing pages that no longer exist locally. Writes nothing when the content has not changed, so page histories stay readable.

  • Java 21
  • Maven Plugin
  • Antora
  • AsciiDoc
  • Confluence Cloud
